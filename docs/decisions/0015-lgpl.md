# 0015 — Everything under LGPL-3.0-only, OSRD's simulation core in the repository

Status: **accepted** — replaces [0002](0002-licences.md) for the licences (the sign-off stands); changes
[0013](0013-running-times-in-rust.md) points 2 and 3 and [0006](0006-capacity-on-osrd.md) point 5

## Decision

1. **The whole repository is under the GNU Lesser General Public License v3.0 only** (`LGPL-3.0-only`): code,
   schemas, documentation and pictures of the project's own alike. `LICENSE` holds the LGPL, `LICENSE-GPL` the
   GPL-3.0 it builds on; `LICENSE-docs` (CC BY 4.0) is gone. What was published before under Apache-2.0 or
   CC BY 4.0 stays available under those terms in the history; from here on the project's licence is the LGPL.
2. **OSRD's simulation core in Rust is in the repository**, under `sim/` — what was the repository
   `rail-across-sim` (0013). The Simulation-Tool still loads it as a WebAssembly module of its own beside the
   page, which can be replaced (`apps/simulation-tool/scripts/sim.mjs` builds it from `sim/`).
3. **OSRD's example vehicles are in the repository** too, unchanged, as the suite's built-in vehicles
   (`packages/vehicles/data/osrd/`, [0014](0014-vehicles-in-osrds-form.md)).
4. **Third-party material keeps its own licence** and is named in THIRD-PARTY.md, as before. Contributions are
   signed off after the DCO, as before; there is no contributor licence agreement.

## Why

- The suite carries a port of OSRD, which is LGPL-3.0; parts of it would otherwise have to live apart from the
  rest — a second repository, a second checkout on every server, two commits for one change, a licence boundary
  through the middle of a feature. One licence for everything removes that.
- OSRD — the base of the capacity simulation (0006) and the source of the running times (0013) — is LGPL-3.0:
  code may move between the two projects in both directions.
- Improvements to the suite itself stay open: whoever changes it and passes it on passes the changes on. The LGPL
  still lets the suite's libraries be used by other programs, also closed ones, which keeps it usable inside
  other products as 0002 wanted.
- Every commit so far is the project owner's; the change needs no one else's consent.

## What it costs

- 0002's aim of the widest use is narrowed: a vendor who changes the suite and distributes it must publish the
  changes. Running it as a hosted service without passing it on does not oblige to anything (unlike AGPL).
- The LGPL is a licence for software; for texts and pictures it is unusual, and anyone who wants to quote the
  documentation has to keep to it. Accepted for one licence across the repository.
- Apache-2.0's explicit patent licence is replaced by the GPL-3.0's (section 11), which LGPL-3.0 takes over.
- Code taken from Apache-2.0 projects can come in (Apache-2.0 is compatible with GPL-3.0 and LGPL-3.0); code
  under GPL-2.0-only cannot.

## Alternatives considered

| Way | Why not |
|---|---|
| Keep 0002, LGPL code in its own repository (0013 as it was) | the cost above: two repositories for one feature |
| Keep 0002, LGPL code in a directory of its own with its own licence | two licences in one repository, every file to be told apart, documentation to keep apart |
| AGPL-3.0 for everything | stricter than OSRD; keeps hosted services open too, but deters operators and offices |
| GPL-3.0 for everything | the suite's packages could not be used by programs under other licences |
